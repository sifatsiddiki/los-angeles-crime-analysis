# los-angeles-crime-analysis
Data analysis project exploring crime patterns, frequencies, and trends in Los Angeles using Python and Pandas.
#  Los Angeles Crime Data Analysis (DataCamp Project)

This project focuses on analyzing crime data from Los Angeles to uncover patterns, behaviors, and trends regarding criminal activities in the city. The project explores key metrics such as the peak hours for crime, the prevalence of night-time crimes, and crime distribution across different geographic areas.

![LA Skyline](la_skyline.jpg)

##  Key Insights & Findings
- **Peak Crime Hours:** Identified the specific hours of the day when crimes occur most frequently.
- **Night-time Crime Analysis:** Analyzed the distribution and types of crimes committed during late-night hours.
- **Demographic & Location Trends:** Breakdown of crime count across various age groups and Los Angeles areas/neighborhoods.

##  Technologies Used
- **Language:** Python 3
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / DataCamp Workspace

##  Repository Structure
- `notebook.ipynb`: The main Jupyter notebook containing all the Python code, data cleaning, analysis, and visualizations.
- `crimes.csv`: The dataset containing crime records in Los Angeles.
- `la_skyline.jpg`: Visual asset used for the project documentation.

##  How to Run Locally

If you want to run this project on your machine, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com
```

2. Navigate to the project directory:
```bash
cd la-crime-data-analysis
```

3. Install the required dependencies:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

4. Launch the Jupyter notebook:
```bash
jupyter notebook notebook.ipynb
```
